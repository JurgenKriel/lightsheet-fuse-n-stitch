<objective>
Extend 07_direct_fuse.py with two new CLI flags (`--load-positions` and `--zarr-mode`) and change the zarr write index from always-local to absolute-when-r+. These ~30 lines of new code are the entire Python-side enabler for the parallel Stage 2 array job: without them, each array task would re-run NCC (wasting ~8 min) and would truncate the shared zarr on open.

Purpose: Enables Stage 2 array tasks to open the pre-allocated zarr in `r+` mode and write their disjoint Z-slabs using absolute CZI coordinates as zarr indices, which is correct because the full-shape zarr was pre-allocated by Stage 1.
Output: Modified 07_direct_fuse.py where `--load-positions ncc_scores.json --zarr-mode r+` is safe to call from 8 concurrent SLURM array tasks.
</objective>
