# Phase 02.5 Plan 02: 08_stitch.py Stage 1 (register) Summary

**One-liner:** Created `08_stitch.py` (380 lines) implementing Stage 1 (`--stage register`) — a globally-optimised tile registration using `multiview_stitcher.registration.register` with `groupwise_resolution_method="global_optimization"`, replacing the MST + BFS propagation from `07_direct_fuse.refine_tile_positions`. The unchanged dual-side fusion path (`fuse_sides`, `_gaussian_ramp`, `read_tile_zchunk`) is imported via `importlib.import_module("07_direct_fuse")` — STITCH-06 verified clean on protected function bodies.

## What was built

1. **`08_stitch.py`** — new module, 380 lines, `mvstitch_env` Python 3.11 compatible.
   - **Imports** (STITCH-06): `read_tile_zchunk`, `fuse_sides`, `get_czi_layout` are pulled from `07_direct_fuse` via `importlib` after prepending `Path(__file__).resolve().parent` to `sys.path[0]`. The legacy module is read-only from this file's perspective — zero modifications to the three protected function bodies (verified via byte-identical sha256 of HEAD vs worktree, see "STITCH-06 audit" below).
   - **`build_tile_sims(czi, layout, z_slab_start, z_slab_end, …)`** — reads dual-side (or single-side fallback) tile data for `n_tiles` tiles, runs the validated `fuse_sides(axis=2, sigma_frac=0.9)`, and wraps each fused `(Z, Y, X)` ndarray as a `spatial_image.SpatialImage` via `si_utils.get_sim_from_array` with `scale={"z": 3.515, "y": 0.915, "x": 0.915}` µm/voxel and `translation` set from `layout["tile_bboxes"]` (CZI stage metadata, converted px → µm). Used by both stages.
   - **`stage_register(args, czi, layout)`** (STITCH-01 + STITCH-03):
     - Reads a 64-plane Z-slab centred on `n_z // 2` (override via `--z-mid`, `--z-slab-half`).
     - Calls `registration.register(msims, transform_key="stage_metadata", new_transform_key="registered", pairwise_reg_func=registration.phase_correlation_registration, groupwise_resolution_method="global_optimization", post_registration_do_quality_filter=True, post_registration_quality_threshold=0.2, return_dict=True)`.
     - Writes `stitch_positions.json` (`{m_idx: {translation_um, translation_px}}`) and `stitch_diagnostics.json` (library_version, n_tiles, z_slab_used, voxel_size_um, pairwise [{i, j, quality, shift_um, shift_px, residual_px, accepted}], groupwise {method, converged, rms/max_residual_px, n_variables, n_constraints, solver_iterations}).
   - **`stage_blend(args, czi, layout)`** — `NotImplementedError` stub. Plan 02.5-03 will fill it in with `fusion.fuse(..., fusion_func=fusion.weighted_average_fusion, blending_widths={"z": 0, "y": 144, "x": 144}, output_stack_mode="union")` writing to pre-allocated `fused_direct.zarr` in `r+` mode.
   - **CLI** — `--stage {register,blend}`, `--czi`, `--out-dir`, `--out-zarr`, plus Stage-1 knobs (`--z-mid`, `--z-slab-half`, `--reg-channel`, `--quality-threshold`) and Stage-2 placeholders (`--z-start`, `--z-end`, `--z-chunk`, `--blend-y`, `--blend-x`) and shared knobs (`--sigma-frac`, `--fusion-axis`, `--workers`).
   - **Helper serializers** — `_extract_translation_um` (xarray affine → {z,y,x}), `_to_pixels` (µm → px via voxel_size_um), `_flatten_pairwise` (defensive: handles both list-of-dict and dict-of-dict pairwise shapes), `_flatten_groupwise` (fixed schema).

2. **Traceability comment** — file contains `STITCH-06` comment block explaining the importlib pattern and the rule that this file must not modify the three protected functions.
